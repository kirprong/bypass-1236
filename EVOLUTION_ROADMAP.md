# 🧬 Evolution Roadmap: 1234

## 🌟 Grand Vision (Итоговая цель)
1234 превращает "волевое начало работы" в автоматический протокол, который принуждает мозг входить в состояние действия через ритм, звук и визуальные якоря. Продукт эволюционирует от минимального таймера к системе удержания: статистика, лимиты, монетизация и затем расширенные психологические микромеханики (хаос/подтверждение цели).

## 🟢 STAGE 5: Meta Time Scaling (Global Time Warp) ✅ COMPLETED
**Суть:** Глобальный ползунок "мета-масштабирования времени", который сжимает/растягивает темп полного цикла.

- [x] Time Warp Scale UI (0.5x - 2.0x) в SettingsScreen
- [x] _getScaledPhaseDuration() с clamp-валидацией и fallback 1.0
- [x] Guard _phaseCompleted от повторного триггера перехода фазы
- [x] Применение масштаба ко всем фазам: THINKING, PREP, STRIKE, RECOVERY
- [x] Сохранение/восстановление timeWarpScale из SharedPreferences

**Статус:** Завершено в рамках Upgrade Pipeline v1.1.

**Бизнес-ценность:** Качество выполнения за счет управляемого ритма: низкий масштаб = разгон (быстрый прогон фаз), высокий масштаб = глубокое погружение (растяжение фаз), при этом переходы остаются корректными и последовательность фаз не ломается.

**Что делаем:**
- **ТОЛЬКО** добавить глобальный ползунок, который преобразует длительности цикла/фаз по прогрессивному правилу: низкий масштаб сжимает весь цикл, высокий — растягивает; применение масштаба устроено так, чтобы исключить зависание в отдельной фазе (контролируемый темп, не случайность).

**ЧЕГО МЫ НЕ ДЕЛАЕМ:** авторизация, платежи, профили, новые цели/оверлеи — **всё вырезано** (только управление временем цикла).

## 🔜 STAGE 6: Deep Flow Inertia Controller (Auto after Phase 3) [TODO]
**Суть:** После фазы 3 (“Уничтожай”) приложение автоматически переводит пользователя в режим **INERTIA** без каких-либо дополнительных запросов инерции/отдыха.

**Правила INERTIA:**
- **Автовход:** сразу после завершения фазы 3.
- **Pulse (мягкий звуковой сигнал):** уведомляет пользователя, что он всё ещё находится в режиме инерции.
  - Интервал **рандомный 3–6 минут**
  - Тот же тип сигнала, но **не сильно отвлекающий**
- **UI режима:** только одна кнопка **EXIT**.
- **Выход из INERTIA:**
  - При нажатии **EXIT** система **выходит из цикла инерции** и запускает стандартный переход в **режим отдыха**.
  - Дальше поведение как и раньше: отдых → в цель → после цели дальнейшая логика как в текущей системе (либо цель создана, либо нет).
- **Лимит бездействия:** в INERTIA без действия пользователя можно находиться **только 6 циклов**.
- **Проверка после 6 цикла:**
  - появляется вопрос (оверлей): **“Всё ещё в инерции?” / “MAX FLOW REACHED. CONTINUE?”**
  - у пользователя **30 секунд**, чтобы ответить **YES**
  - если ответа **нет** → **автоматический выход в отдых** и далее по обычной логике.
