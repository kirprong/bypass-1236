# Product Requirements Document (PRD) - Stage 0: Анонимный таймер-цикл "1234"

## 1. Stage 0 Overview (Суть этапа)

**ВАЖНО:** В момент выпуска v1.0.0 этап вышел за рамки исходного Stage 0 и включил функционал до Stage 11. Ниже указан фактически реализованный продукт.

1234 Timer реализует 4 фазы с психологической механикой удержания:
- **THINKING (60s)** → **PREP (120s)** → **STRIKE (180s)** → **ПЕРЕЗАГРУЗКА (60-240s случайно)**

Фаза ПЕРЕЗАГРУЗКА имеет скрытый таймер (пульсирующая анимация) и автоматический перезапуск цикла.

---

## 2. The Core User Flow (Пользовательский путь)

### Стандартный цикл:
1. Пользователь видит "ФАЗА 1. THINKING" и "01:00"
2. Нажимает **СТАРТ** → таймер работает
3. По окончании THINKING: оверлей "ЦЕЛЬ НАЙДЕНА?" (ДА/НЕТ)
4. ДА → переход к PREP (автоматический запуск)
5. НЕТ → сброс к THINKING (автоматический запуск нового цикла)
6. После PREP → STRIKE (автоматически)
7. После STRIKE: выбор "⚡ ИНЕРЦИЯ" или "🧠 ОТДЫХ" (30 сек таймаут)
8. ИНЕРЦИЯ: режим потока с таймером секунд
9. ОТДЫХ: случайная длительность (1-4 мин), пульсация вместо таймера
10. После ОТДЫХА: автоматический переход к THINKING (новый цикл)

### Управление:
- **СТАРТ/ПАУЗА (toggle):** запуск/пауза таймера
- **СБРОС:** полный сброс к начальному состоянию
- **ИНЕРЦИЯ:** после STRIKE (только Premium)
- **ОТДЫХ:** после STRIKE (все пользователи)

## 3. Core Features & Acceptance Criteria

**Feature 1: Таймер-цикл "1234"**
- 4 фазы: THINKING → PREP → STRIKE → ПЕРЕЗАГРУЗКА
- Автопереходы с звуками
- Скрытый таймер в фазе ПЕРЕЗАГРУЗКА

**Feature 2: Target Confirmation (Stage 6)**
- Оверлей после THINKING
- Зацикленный beep.mp3 (20 минут)
- Кнопки: "ДА (ОРУЖИЕ К БОЮ)" / "НЕТ (НАЗАД К ПОИСКУ)"

**Feature 3: Inertia Mode (Stage 5)**
- Кнопка "⚡ ИНЕРЦИЯ" после STRIKE
- Таймер в секундах вместо mm:ss
- Бонусный отдых за инерцию

**Feature 4: Chaos Protocol (Stage 7)**
- Случайная длительность ПЕРЕЗАГРУЗКИ (60-240 сек)
- Пульсирующая анимация вместо таймера
- Автозапуск нового цикла

**Feature 5: Audio System (Stage 8)**
- 8 звуковых эффектов
- Предупреждение за 6 секунд
- Dead Man's Switch звук

**Feature 6: Local Stats (Stage 9)**
- Сохранение strikes и времени инерции
- Экран статистики
- Расчет общего времени доминирования

**Feature 7: Rank System (Stage 10)**
- 15 уровней рангов
- Визуальное отображение текущего ранга
- Геометрическая прогрессия

**Feature 8: Paywall (Stage 11)**
- Лимит: 3 цикла/день (Free)

## Version 1.1 - Upgrade: Meta Time Scaling (Global Time Warp)

### 1. Upgrade Overview & Business Goals
Добавляем глобальный ползунок “мета-масштабирования времени”, который позволяет управлять темпом полного цикла работы (всеми фазами в заданной последовательности) без изменения порядка фаз. Цель — повысить качество выполнения за счет управляемого “разгона/погружения” и снижения риска “залипания” в одной фазе.

### 2. Impact on Existing System (Влияние на текущую систему)
- **Затронутые старые модули:** таймер-цикл “1234” (длительности фаз THINKING → PREP → STRIKE → ПЕРЕЗАГРУЗКА), визуализация таймера/прогресса, логика авто-переходов по окончанию фаз.
- **Изменения в поведении:** длительности фаз теперь динамически масштабируются параметром Meta Time Scaling. При этом порядок фаз и условия переходов сохраняются (THINKING → PREP → STRIKE → ПЕРЕЗАГРУЗКА не меняются).

### 3. New Features & Acceptance Criteria
**Feature 1.1.1: Global Meta Time Scaling Slider (Time Warp)**
- Описание: в UI появляется глобальный ползунок масштаба времени, который влияет на длительности всех интервалов/фаз во всех последовательностях.
- AC1: Пользователь может изменить масштаб времени, и значение влияет на тайминг фаз **без смены порядка фаз** (THINKING → PREP → STRIKE → ПЕРЕЗАГРУЗКА).
- AC2: Изменение масштаба во время RUNNING приводит к корректному пересчету “момента окончания фазы” так, чтобы авто-переходы продолжали срабатывать **ровно один раз на завершение каждой фазы** (guard от повторного триггера на одном и том же тике).
- AC3: При низком масштабе цикл работает быстрее (фазы короче), при высоком — медленнее (фазы длиннее).
- AC4: Логика исключает зависание на одной фазе: окончания фаз и авто-переходы продолжают происходить по корректно масштабированному таймеру (не требуется ручной сброс для продолжения цикла).

**Feature 1.1.2: Distinction от Chaos Protocol**
- Описание: Meta Time Scaling — контролируемый параметр, а не случайная длительность.
- AC1: В отличие от Chaos Protocol, Meta Time Scaling не вводит случайность длительности фаз; изменение темпа определяется значением ползунка.
- AC2: Chaos Protocol продолжает работать как есть для фаз, где он задуман, а Meta Time Scaling лишь масштабирует темп.

### 4. New Success Metrics (Метрики успеха)
- Увеличение доли пользователей, которые проходят полный цикл без ручного “СБРОС” при изменении масштаба времени.
- Рост повторных запусков цикла (retention) в сессиях после изменения Meta Time Scaling.
- Снижение частоты “залипания”/ошибочных сценариев авто-переходов (по логам таймера и событий фаз).
